## What I'm Working On

### 🧠 Brane
**Shared memory for developer + agent systems**

- Captures architectural decisions, debugging context, tribal knowledge, and agent traces automatically.
- Makes project knowledge searchable, reusable, and cumulative across humans and agents.
- Reduces context collapse from agent-assisted development.
- Designed for on-prem and enterprise control.

Core thesis:  
> Agent velocity is no longer the bottleneck. Coordination and memory are.
